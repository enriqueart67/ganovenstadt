# Ganovenstadt

3D-Browserspiel im GTA-Stil mit Multiplayer.

Spielen: https://enriqueart67.github.io/ganovenstadt/spiel.html

## Krawall-Schach

Schach gegen Freunde – online per Raum-Code/Link oder zu zweit an einem Gerät, mit krassen Schlag-Animationen.

Spielen: https://enriqueart67.github.io/ganovenstadt/schach.html

## Nadeljagd

Kletter-Spiel: Den Heuturm hochklettern, unterwegs Save-Spots setzen (Fortschritt bleibt gespeichert) und oben die Nadel im Heuhaufen finden – allein oder mit Freunden per Raum-Code/Link.

Spielen: https://enriqueart67.github.io/ganovenstadt/nadel.html
